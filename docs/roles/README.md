# Документы по ролям

В этой папке находятся короткие целевые версии документации для разных участников проекта.

| Документ | Роль | Назначение |
|---|---|---|
| `DEVELOPER_GUIDE.md` | разработчик | архитектура кода, локальный запуск, тесты, точки расширения. |
| `IMPLEMENTATION_GUIDE.md` | внедренец | порядок внедрения, сбор id, проверка REST-контрактов и rollout. |
| `IMPLEMENTER_PROD_MINIMAL.md` | внедренец | минимальная prod-настройка: адреса, креды, queue id и branch→entry point mapping. |
| `APPLICATION_YML_EXTENDED.md` | внедренец/эксплуатация | расширенная расшифровка всех ключей `application.yml` по блокам. |
| `SUPPORT_GUIDE.md` | техническая поддержка | диагностика, симптомы, логи, эскалация. |
| `TESTER_GUIDE.md` | тестировщик | функциональные, интеграционные и негативные сценарии. |
| `SALES_GUIDE.md` | продажник/пресейл | бизнес-ценность, ограничения, демо-сценарий и ответы заказчику. |

PDF-версии формируются в `docs/pdf/`.
