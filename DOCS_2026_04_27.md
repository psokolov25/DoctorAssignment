## Особый акцент в документации

- Режим med-robot `TICKET_NUMBER_PLAIN_TEXT` должен отправлять номер талона как plain text, а не JSON.
- Для Micronaut client `@Produces(text/plain)` управляет request `Content-Type`, а `@Consumes(application/json)` - request `Accept`.
- По актуальному состоянию на 2026-04-28 отдельный `POST add-service` не выполняется: услуга, выбранная med-robot, передается в обычный `assign-service`.
- `fromId` в transfer payload берется из `source-entry-point-id-by-branch`, и это нужно проверять по runtime-аудиту.

> Примечание: актуальные уточнения по маршрутной дедупликации и отказу от описания `POST add-service` как рабочего режима см. в `DOCS_2026_04_28.md`.
