# Диаграммы PlantUML

Диаграммы хранятся как исходники PlantUML в `docs/plantuml/*.puml` и как готовые SVG в `docs/diagrams/*.svg`.
PNG-копии намеренно не используются: SVG масштабируется без потери качества и лучше подходит для HTML/PDF-документации.

## Генерация SVG штатным PlantUML

```bash
plantuml -tsvg -o ../diagrams docs/plantuml/*.puml
```

Файл `common-style.puml` задает единый профиль оформления: шрифт без засечек, отключенные тени, прозрачные подписи групп и сообщений, короткие переносимые подписи, единые цвета для компонентов, артефактов, баз данных, узлов и заметок.
