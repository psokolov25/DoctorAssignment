# Диаграммы PlantUML

Диаграммы проекта хранятся в двух форматах:

- исходники PlantUML: `docs/plantuml/*.puml`;
- подготовленные SVG для публикации в Markdown/PDF: `docs/diagrams/*.svg`.

PNG-копии намеренно не используются: SVG масштабируется без потери качества, корректно встраивается в README и сохраняет читаемость русских подписей.

## Что входит в набор

- архитектурные и deployment-диаграммы;
- sequence/state/decision-диаграммы сценариев назначения;
- карты контрактов интеграции с Orchestra и med-robot;
- эксплуатационные схемы (наблюдаемость, отказоустойчивость, polling/reconciliation).

## Единый визуальный стиль

Файл `common-style.puml` задает единый профиль оформления:

- шрифт без засечек (`Segoe UI`);
- отключенные тени и лишние декоративные эффекты;
- прозрачные подписи групп и сообщений;
- переносимые подписи для длинных технических фраз;
- единая палитра для компонентов, артефактов, баз данных, узлов и заметок.

Каждая диаграмма обязана подключать общий стиль через:

```plantuml
!include common-style.puml
```

## Быстрая регенерация SVG

```bash
plantuml -tsvg -o ../diagrams docs/plantuml/*.puml
```

## Рекомендуемая проверка перед коммитом

```bash
./mvnw -q -Dtest=DocumentationAssetsTest test
```

Тест проверяет, что документационные файлы читаемы в UTF-8, диаграммы содержат русские заголовки и ссылки на SVG/PlantUML в актуальном виде.
